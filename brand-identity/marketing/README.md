# Neoverse DTS - Marketing Materials

## 📦 Contents

This folder contains ready-to-use marketing materials for Neoverse Digital Transformation Solutions.

### Available Materials

#### 1. One-Pager (`one-pager.html`)
**Size**: A4 (210mm x 297mm)

**Purpose**: Comprehensive one-page overview of Neoverse DTS

**Includes**:
- Company overview
- All 5 service lines
- Key statistics and credentials
- Target audience
- Contact information

**How to Use**:
- Open in any web browser
- Print to PDF (File > Print > Save as PDF)
- Share digitally or print for meetings

---

#### 2. Business Cards

**Size**: Standard business card (85mm x 55mm / 3.5" x 2")

**Files**:
- `business-card-front.html` - Front side (gradient design with logo)
- `business-card-back.html` - Back side (contact info and services)

**Features**:
- Premium gradient design
- QR code placeholder
- Professional contact layout
- Service highlights

**How to Use**:
1. Edit the HTML files to add your personal information:
   - Replace `[Your Name]` with your name
   - Replace `[Your Title]` with your job title
   - Update contact information
2. Open in browser
3. Print to PDF at actual size (85mm x 55mm)
4. Send to professional printer
5. Optional: Add QR code before printing

**Printing Tips**:
- Use 350gsm card stock
- Recommend matte or silk finish
- Print on premium quality paper
- Verify dimensions before bulk printing

---

#### 3. Presentation Template (`presentation-template.html`)

**Format**: 16:9 widescreen slides

**Includes**: 6 ready-to-use slides:
1. **Title Slide** - Company name and tagline
2. **Who We Are** - Company overview and credentials
3. **Our Services** - 4 main service lines
4. **Why Choose Us** - Key statistics and differentiators
5. **Who We Serve** - Target audience
6. **Contact Us** - Call to action and contact info

**How to Use**:
- Open in browser to preview all slides
- Take screenshots of each slide for PowerPoint
- Or use directly as web-based presentation
- Print to PDF for handouts

**Customization**:
- Edit HTML to change text content
- Modify colors in the CSS section
- Add your own slides by copying existing slide blocks

## 🚀 Quick Start Guide

### For One-Pager:
```bash
1. Open one-pager.html in Chrome/Edge
2. Press Ctrl+P (Windows) or Cmd+P (Mac)
3. Select "Save as PDF"
4. Choose A4 paper size
5. Uncheck headers/footers
6. Save and share!
```

### For Business Cards:
```bash
1. Edit HTML files with your information
2. Open in Chrome/Edge
3. Print to PDF at actual size (85mm x 55mm)
4. Send PDF to professional printer
5. Recommend: Order sample before bulk printing
```

### For Presentation:
```bash
1. Open presentation-template.html in browser
2. Review all 6 slides
3. Customize text as needed
4. Either:
   - Use as web presentation (full screen mode)
   - Screenshot each slide for PowerPoint
   - Print to PDF for handouts
```

## ✏️ Customization Guide

All files are HTML with embedded CSS, making them easy to customize:

### Changing Text:
- Open HTML file in any text editor
- Find the text you want to change
- Replace with your content
- Save and refresh browser

### Changing Colors:
- Find the `<style>` section in the HTML
- Locate color codes (e.g., `#0A2463`)
- Replace with your preferred colors
- Save and refresh

### Adding Content:
- Copy existing content blocks
- Paste and modify
- Adjust spacing if needed
